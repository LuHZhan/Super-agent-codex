# 以个人本地 Codex 主动助手为目标

2026-11-02：用户确定系统个人本地运行，使用本人 Codex 订阅额度，Router 和 Worker 都由 Codex 承担；参考 dsh-superagent，但不要求以 dsh 为运行宿主。订阅接入需遵守官方认证方式和额度限制，这一决定不表示任何特定 SDK 或接口已验证可用。

系统必须具备在预设授权范围内主动发现并启动工作的能力。仅持续跟进用户明确交办的任务，与用户现有 Codex 使用体验重叠，不能满足本项目的主要诉求。
